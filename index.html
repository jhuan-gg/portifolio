01. SOBRE MIM

Curioso por natureza.
Dev por escolha.

Jhuan GabrielDesenvolvedor Full Stack

Sou engenheiro de software e transformo regras de negócio em sistemas web estáveis, seguros e fáceis de evoluir. Trabalho de ponta a ponta: do modelo de dados e da API até a interface que o usuário final usa.

No front-end, trabalho com React e Next.js, organizando componentes com Atomic Design e cuidando da performance. No back-end, uso Node.js e TypeScript para construir APIs REST e GraphQL sobre bancos relacionais e NoSQL.

Aplico SOLID e Clean Architecture para manter o código legível, testável e escalável. Levo o que construo até a produção, com Docker, CI/CD e deploy em nuvem.

Combino AI-assisted development com programação convencional, escrita de código manual, revisão e resolução de bugs. Uso IA para acelerar tarefas, explorar soluções e apoiar decisões técnicas, mantendo a responsabilidade pela implementação e validação. Meu foco é a proatividade, a entrega rápida e a construção de software sustentável, escalável e profissional.
